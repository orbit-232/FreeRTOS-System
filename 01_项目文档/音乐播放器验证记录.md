## 2. 最小音乐启动

`main.c` 已从 `panel_services_init()` 改为
`panel_services_init_music_only()`。新路径只执行：

1. 默认亮度/背光；
2. `panel_files_init()`（SDMMC slot 0/TF）；
3. `panel_audio_init()`（共享音频 worker）；
4. `panel_music_init()`（唯一音乐 worker）。

不再创建 Wi-Fi、BLE、天气、时钟、外置字体、锁屏壁纸等业务任务。
ESP-Hosted transport 构造函数仍负责共享 SDMMC controller/slot 1，TF slot 0 挂载
依赖它，因此保留该底层依赖；没有启动网络业务。该启动边界需实板冷启动日志确认。

符号检查：最终 ELF 中存在 `panel_services_init_music_only`、
`panel_music_ui_start`、`panel_music_ui_start_console`；不存在
`panel_services_init`、`panel_network_init`、`ui_page_home_create`。

```text
INDEX_OK file=track0 frames=13823 duration_ms=361090 entries=1728 first=882172 fmt=MPEG1/44100Hz/2ch
```

索引按物理帧计时，首 Info/Xing 帧计入时间轴，与 minimp3 物理帧口径一致。
扫描按 16 KiB lease 读取，每块释放 TF 锁并检查取消；不整曲持锁。

### 4.2 截断/取消/长曲

```text
TRUNCATED_INDEX_REJECTED error=truncated MP3 frame
CANCEL_INDEX_OK reads=1
IO_ERROR_INDEX_REJECTED error=TF read failed
LONG_INDEX_OK frames=20000 duration_ms=522448 entries=1250 floor_ms=469368
VBR_INDEX_OK frames=400 duration_ms=10448 entries=50 target_ms=5000 floor_ms=4597
```

长曲触发索引抽稀/步距翻倍，仍可覆盖 90% 位置；无索引越界回退。

### 4.3 真实 PCM 对照

对四首真实 MP3 的 0/25/50/90% 共 16 个窗口，各 4096 帧、44.1 kHz 双声道：

```text
MP3_PCM_SEEK_TESTS_OK checks=16 compare_frames=4096
```

全部窗口 `max_diff=0`、`rms=0.000`。对照方式是“线性解码参考 PCM”与
“索引 seek + 预滚 + 目标样本裁剪 PCM”逐样本比较，不是只比较索引时间。
代表性输出：


直接编译并运行生产 `panel_music.c`，以 Windows 线程、真实 MP3 硬链接和节流假

```text

```

覆盖：

- 四首预索引命中（`source=prebuilt`）与逐首时长；
- 播放中 seek、暂停连续拖动、恢复、播放中连拖、越界钳制；
- 预索引 seek 的 16 个 PCM 窗口对照线性解码，`max_diff=0`；
- 临时副本真实修改末字节/采样字节后指纹不匹配，触发完整扫描回退；
- 预索引 I/O 错误直接报错，不盲扫；
- 预索引发布点被 next 打断时旧 generation 不发布 READY；
- 慢打开/切歌/停止竞争、旧 `file_open` 错误不覆盖新曲；
- seek 帧头不符时清 pending 并继续当前播放；
- 音频错误后停止清理索引标志；
- FILE lease / mount pin 平衡，无递归锁。

## 8. 明确未证明/未实现

- 当前板上已完成有限人工验收（开播、四曲切换、拖动、声音、屏幕正常），但长期
  连续播放、反复切歌、边界 seek、异常卡/坏文件等未覆盖；心跳正常不等于全面验收。
- 原 20 fps 封面旋转在实板播放时导致屏幕卡住，当前诊断镜像关闭旋转；恢复策略
  未定，不把关闭当作最终方案。
- 预索引为 16 处抽样指纹，不是全文件哈希；未采样区域修改可能检测不到。文件大小/
  ID3/采样不符才回退完整 16 KiB 扫描，整扫约 13.5 秒，不宣称快速启动。
- TF 读错误直接报错，不能当作普通不匹配继续盲扫；seek 帧头不符必须清 pending，
  不得假报成功。
- 64 KiB 同步读取和并行双文件候选在实板出现 `0x107` SDMMC 超时，已停止该路线，
  只作为历史失败结果保留。
- ESP-Hosted 底层任务因 SDMMC slot1/共享控制器仍启动；未宣称网络栈完全移除。
- `esp_codec_dev_close()`/I2S disable 能停止并关闭输出，但“DMA 已写入样本完全
  清零”未由主机证明；不宣称已证明，列为实板听感验证项。
- 收藏/随机/循环/音量仍是运行期状态，未写 NVS。
- 列表/歌单、队列、下载、更多、最小化未实现，按钮只显示明确不可用提示。
